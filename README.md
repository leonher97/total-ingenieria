# Total Ingeniería del Norte

Sitio web estático actualizado a partir del proyecto original.

## Cambios principales
- Marca y textos actualizados a **Total Ingeniería del Norte**.
- Interfaz completamente en español.
- Logo proporcionado por el cliente integrado como imagen de marca y favicon.
- Paleta inspirada en el logotipo: negro, azul eléctrico, acero y blanco.
- Servicios:
  - Tomas de fuerza.
  - Reparación de cilindros hidráulicos.
  - Servicio de torno y fresadora.
  - Soldadura.
  - Mecánica diesel agrícola y minería.
  - Generación de energía.
- Página de sectores/aplicaciones.
- Formulario de cotización que genera y copia una solicitud lista para compartir.
- Diseño responsive para escritorio, tablet y móvil.
- Sin dependencias JavaScript externas.

## Estructura
- `index.html` — inicio
- `services.html` — servicios
- `projects.html` — sectores y aplicaciones
- `quote.html` — solicitud de cotización
- `css/styles.css` — estilos
- `js/main.js` — navegación, animaciones y formulario
- `assets/total-ingenieria-del-norte.png` — logo
- `assets/favicon.png` — favicon compacto derivado del logo
